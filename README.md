# Proyecto Generador seguro de contraseñas
Integrantes: David Balladares
Objetivo del sistema : Desarrollar un codigo generador de contraseñas seguras con una encriptacion basica ocupando los conocimientos adquiridos en el curso de logica de programacion para disminuir los riesgos de la seguridad digital.
Descripcion de funcionalidades:
-Generacion aleatoria: Se utiliza librerias de pyhton para generar contraseñas aleatorias basadas en un conjunto de datos
-Estructuras de control: Aumenta la robustez del codigo para solicitar longitud minima de caracteres e ingreso de usuario
-Manejo de errores: Mediante try-except evitamos el colapso del codigo 
-Estructuras condicionales: Con el uso del if,permite que el codigo tome decisiones logicas
-Encriptacion de codigo: se utilizo el metodo de ofuscacion
